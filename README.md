# Al Majlis

A virtual majlis for remote and multinational teams: a shared room with a Saudi Arabia and Pakistan quiz, Draw & Guess, and Team Pool, played live by everyone at the same time.

Created by Batool. Built with the help of AI (Claude).

## Play
Open the link, type your name, pick your country, and enter.
Private room for your team: add `?room=yourcode` to the end of the link.

## Host
Open "I'm the host" on the entry screen and type the host PIN from `config.js`.

## Setup
1. Paste your Firebase web config in `config.js`.
2. Paste `database.rules.json` into Firebase > Realtime Database > Rules, then Publish.
3. Upload all files to the GitHub repository and turn on GitHub Pages.
